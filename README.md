# Minimal Flask "Hello World" Web Service

A simple Python web service built with Flask that returns a "Hello, World!" message when accessed via a browser.

## 🛠️ Development Environment Setup

- **Language:** Python 3.14
- **Framework:** Flask 3.0.3
- **Editor:** Visual Studio Code (VS Code)
- **Terminal:** Command Prompt (CMD) / PowerShell

### Installation Steps
1. Created a new project folder `flask-hello-world`.
2. Opened the folder in VS Code.
3. Installed Flask using pip:
   ```bash
   pip install Flask
